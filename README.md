# Mad-Avionics
1.1 Diable Avionics Addon mod for Starsector

## Acquisition
- Godhead - Find its blueprint or . Down the line I might add a dedicated quest but I have no idea how to. Till then either spawn it in for 10 million credits, or find the blueprint somewhere in the world, or get lucky with any of the random ship acquisition quests. (I assume this is possible, I've yet to find it)
- Drought - Rare but can be found in diable avionic stores
- Flood - Freighter and Tanker can be found commonly in diable avionics stores.
- Mirage - I believe I put it in one of the diable blueprint packs but otherwise same story as Godhead
